# 走近抚州市花

抚州市双市花玉茗花与荷花的城市文化调研网页。项目以“一城两花，四时有信”为线索，梳理两种市花的自然生境、历史文脉、公共决策和当代生活，并通过季节切换、双花对读、赏花路线与花印集章完成交互呈现。

- 玉茗花与荷花的植物档案
- 2013年7月31日双市花确立节点
- 自然环境、历史文化、社会生活与双花互补分析
- 冬春赏玉茗、盛夏赏荷的路线建议
